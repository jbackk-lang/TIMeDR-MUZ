# Szablony pism (wersjonowane)

Każdy szablon ma wersję w nazwie pliku, a jego hash trafia do planu i pokwitowania. Szablony są wzorami roboczymi i przed pierwszym użyciem powinien je sprawdzić prawnik (dokument MUZ, bramka P3). Pola w nawiasach klamrowych wypełnia wykonawca z potwierdzonych danych umowy i profilu użytkownika.
